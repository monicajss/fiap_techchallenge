# FIAP Tech Challenge

Repositório criado para concentrar todos os Tech Challenges do curso de Pós Tech em Data Analytics da FIAP.

## Sobre este repositório

Este espaço será utilizado para organizar, documentar e versionar as entregas desenvolvidas ao longo das fases do curso. A ideia é manter em um único lugar os materiais produzidos em cada etapa, facilitando o acompanhamento da evolução do projeto, o histórico das decisões e a reutilização de artefatos.

Aqui poderão ser armazenados, por exemplo:

- códigos-fonte
- notebooks
- bases de apoio
- documentação técnica
- apresentações
- evidências das entregas

## O que é o Tech Challenge

O Tech Challenge é o projeto integrador da fase, construído a partir dos conhecimentos desenvolvidos nas disciplinas do curso. Em geral, trata-se de uma atividade em grupo, com foco prático e aplicada a problemas próximos do mercado.

De acordo com as informações públicas da Pós Tech da FIAP, a metodologia do curso adota Project Based Learning (PBL), com uma jornada estruturada em 5 fases de um projeto completo. No FAQ da Pós Tech, a FIAP informa que:

- ao final de cada fase, há a entrega de um Tech Challenge relacionado às disciplinas cursadas
- a avaliação da Pós Tech inclui Tech Challenge, Hackathon Experience e atividade presencial
- os cursos são hands-on, 100% digitais e organizados em torno de projeto prático

Além disso, conforme o contexto deste repositório, o Tech Challenge representa uma atividade obrigatória e possui peso relevante na composição da nota final.

## Objetivo

Centralizar os entregáveis dos desafios da pós-graduação em Data Analytics, mantendo uma base organizada para:

- registrar a evolução do projeto ao longo das fases
- consolidar aprendizados das disciplinas
- facilitar colaboração entre integrantes do grupo
- manter histórico de entregas e versões
- compor portfólio acadêmico e técnico

## Organização sugerida

Conforme os desafios forem sendo adicionados, uma estrutura como a abaixo pode ser adotada:

```text
fiap_techchallenge/
├── README.md
├── fase-1/
├── fase-2/
├── fase-3/
├── fase-4/
└── fase-5/
```

Dentro de cada fase, podem ser incluídos arquivos como:

- `README.md` da fase
- código da solução
- notebooks de análise
- datasets ou instruções para obtê-los
- relatórios e apresentações

## Próximos passos

À medida que os desafios forem sendo desenvolvidos, este repositório poderá ser expandido com:

- estrutura por fase
- instruções de execução
- padronização de documentação
- automações de validação
- templates para entrega
